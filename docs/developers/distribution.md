# 导入、列表与更新

支持代码、本地 JS、本地 JSON 列表与 URL。下载后识别内容，不依赖扩展名。生产分发使用 HTTPS。

```json
{
  "name": "我的插件集",
  "plugins": [
    { "id": "example.hello", "name": "虚构示例", "version": "1.0.0", "url": "plugin-hello.js" }
  ]
}
```

标准名为 manifest.json。其他文件名不改变内容识别，建议统一标准名称。列表上限 1 MiB、500 条，JS 上限 2 MiB。

本地条目相对于列表所在目录；远程条目以重定向后列表最终 URL 为基准。预览只展示元信息，确认后只下载勾选条目。文件 meta.id/version 与列表不符时仅该条失败。

**Android 限制：** 已支持文档选择器 content URI 单文件读取，尚未取得兄弟文件的目录授权。此类列表暂用绝对 HTTPS 条目，或分别选择 JS；桌面相对路径测试不能证明 Android 也支持。

## 更新

版本按数字段比较。同 ID 更高版本更新，同版本覆盖用于调试，降级需确认。更新保留有效设置与持久数据，新修订使旧会话失效。安装和初始化成功是不同状态，失败可恢复上一可用文件。

更新地址：meta.updateUrl → 来源 JS 或来源列表 → 无。订阅可手动刷新列表。启动检查同地址至少间隔 24 小时；手动不受限制。自动安装默认关闭，播放期间延后安装。详见[文件协议](../plugin-protocol/01-plugin-file.md)。
